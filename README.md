# Content Machine

Проект для создания контент-машины вертикального видео под Reels, TikTok и YouTube Shorts.

## Цель проекта

Создать модульную систему, которая помогает регулярно производить вертикальные видео:

1. искать вирусные идеи;
2. собирать контент-план;
3. писать сценарии;
4. готовить визуальную концепцию;
5. создавать сцены и персонажей;
6. собирать видео;
7. готовить публикации;
8. анализировать результаты;
9. улучшать следующие ролики на основе данных.

## MVP 0.1

Первый этап проекта не пытается сразу закрыть всю систему. Цель MVP 0.1: собрать минимальный рабочий контур.
